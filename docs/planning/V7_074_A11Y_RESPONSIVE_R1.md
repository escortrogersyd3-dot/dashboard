# V7-074 accessibility and responsive fidelity

`OTP-V7-074-A11Y-RESPONSIVE-R1` preserves the frozen V7 shell while adding only accessibility and responsive safeguards:

- a visible-on-focus skip link targets the named main landmark;
- desktop and mobile navigation retain accessible names and keyboard buttons;
- native dialog focus containment, Escape close and opener-focus return remain the reused browser interaction path;
- focus indicators use the existing V7 orange token;
- reduced-motion users receive non-animated navigation; and
- existing 600px/880px layouts keep one-column module cards and two-column camera placeholders without horizontal overflow.

It does not authorize a visual redesign, third-party tracking, network, live ObserverOS reads, data authority, database, credentials, media, AI, or permission policy.
